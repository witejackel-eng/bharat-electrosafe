   851→   851→
   852→   852→## Motion 1 — header arrival and compression
   853→   853→
   854→   854→Initial page load:
   855→   855→
   856→   856→- Header opacity 0 → 1
   857→   857→- TranslateY -12px → 0
   858→   858→- Duration 500ms

   862→   862→
   863→   863→- Height compresses
   864→   864→- Descriptor fades
   865→   865→- Shadow changes
   866→   866→- Duration 300–400ms
   867→   867→
   868→   868→## Motion 2 — hero text stagger
   869→   869→
   870→   870→Animate:
   871→   871→
   872→   872→1. Eyebrow
   873→   873→2. H1
   874→   874→3. Supporting copy
   875→   875→4. System labels
   876→   876→5. CTA
   877→   877→
   878→   878→Values:
   879→   879→
   880→   880→- Opacity 0 → 1
   881→   881→- TranslateY 18px → 0
   882→   882→- Stagger 60–90ms
   883→   883→- Duration 550–700ms
   884→   884→- Easing: `cubic-bezier(0.22, 1, 0.36, 1)`

   888→   888→For major images:
   889→   889→
   890→   890→- Wrapper overflow hidden
   891→   891→- Image scale 1.035 → 1

   893→   893→- Duration 700–900ms

   912→   912→- Trigger once
   913→   913→- No dependency required
   914→   914→
   915→   915→Do not turn whole static pages into Client Components.

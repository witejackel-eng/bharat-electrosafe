# Bharat Electrosafe — Original-site product refresh execution assets

This pack is intentionally small. It contains the best original-site product imagery
selected for the current redesign, plus a few clearly labelled approved client assets
needed for IEC, Geo Membrane and the requested WHITE Bharat Hydro Seal treatment.

## Absolute implementation rules

1. Do not bulk-import the whole pack. Copy only assets actually used.
2. Never use old TM logo assets or Tata-branded images.
3. Do not use black Bharat Hydro Seal imagery in the redesigned public website.
4. IEC marking images are TECHNICAL SUPPORT visuals — not full-page hero imagery.
5. For the IEC page, use the clean product renders to show the product family and
   use the IEC marking close-ups only as small compliance/marking evidence.
6. Menu/home visuals must reuse the same central product-image mapping so the
   header, homepage and /products never drift apart.

as equal card heroes in the same row.
